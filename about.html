About 640K Games

640K Games is a one-person studio. I grew up on 8-bit home computers, then the 16-bit machines, then early-90s PCs, and the games I want to make are the ones I remember from that last stretch: painted 256-colour sprites, parallax starfields, a sound card doing its best, and a whole game that fit on a couple of floppy disks.

The name comes from the memory limit that every PC game of that era had to squeeze into. It seemed like plenty at the time.

What we make

Small, replayable arcade games that run in a browser tab. No installs, no accounts, no launchers. The first is Spore Wars, a vertical shoot-'em-up.

How the games are built

The games are written in plain JavaScript on an HTML5 canvas, with no engine, so each one is a single small file. I'm not a programmer by trade; I design and direct, and AI coding assistants write and review the code under my instruction. The art is a mix of openly licensed sprite packs, reworked to a shared palette, and original illustrations. Every third-party asset is listed on each game's page and on the credits page.

Where to play

The games are published on free game portals, starting with itch.io. They are free to play, and the portals' ads are how the studio earns anything. This site is the front door; the games live on the portals.
